# KF2AutoGrenades
Game automation tool for XP Grinding in Killing Floor 2

tldr: Clone the repository, put the map in `KF2/KFGame/BrewedPC/Maps`, launch the game, build the project in C# and run the executable.

I forgot to include a release build, stay tuned for that.

Idk if this is illegal by TWI's standards, though I doubt it since this doesn't use any exploits or modify the game files. It just automates the process of throwing grenades for XP grinding.
